The staff console dialogs and panels that are opened from the case view. Show each as a modal on top of a dimmed case page.

**PLATFORM:** Web, Desktop-first (1280px)

**FRAMES:**
1. **Document review (STF-04):** a large modal with a document preview area (a PDF page shown with zoom controls) on the left and a 320px side panel on the right. The side panel shows the document type, file name, size and upload time, plus the actions "Verify" (with an optional note field) and "Reject" (required reason select and a message field).
2. **Verification decision (STF-05):** a small dialog "Bank account check needs a decision" with the lines "Holder name on bank: SAMPLE TRADERS" and "Business name: Sample Traders Pvt Ltd", a "Name match 71" chip, a required reason select, and the buttons "Accept" and "Reject".
3. **Request changes (STF-06):** a dialog with:
   - a multi-select checklist of steps (Business details, Documents, Bank account, White-label setup, …)
   - a "Reason" select
   - a "Message to applicant" textarea with a "0 / 1000" counter
   - a "Days to fix" number field (default 15, allowed 1–90)
   - a note "This clears earlier recommendations"
   - the buttons "Send request" and "Cancel"
4. **Recommendation (STF-07):** a dialog "Recommend approval" with a note field and the info line "A different approver must make the final decision."
5. **Final decision (STF-08):** three dialog variants:
   - "Approve application" with a note field.
   - "Reject application" with a reason select, a "Message to applicant (shown to them)" field and a visually separated "Internal note (staff only)" field, plus a danger "Reject" button.
   - "Put on hold" with a reason select.
   - Error variants: "You claimed or recommended this case, so another approver must decide." and "Can't approve yet:" followed by a list of reasons.
6. **PII reveal (STF-09):** a dialog "Reveal full value", with a field select (PAN / Account number / Mobile / Email) and a required "Purpose" field. After reveal, the value shows in a monospace chip with the note "This view is logged. The value is hidden when you close this dialog."
7. **Audit trail (STF-10):** a full-width tab panel listing events oldest first, each with a time, actor, action and entity, using tabular figures.
8. **Permission states (STF-11):** three small inline cards: "Claim this case to act on it", "You don't have permission for this action", "Your account isn't enabled for the console".
